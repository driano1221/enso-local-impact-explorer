# Contributing to ENSO Local

Please open an issue before changing scientific interpretation or data acquisition.

For a bug, include the locality, measure, season, display scale, language, browser and steps to reproduce. A screenshot can help; omit personal information and credentials.

Keep climate values and provenance separate from presentation changes. Missing data must remain missing. Source agreement does not establish accuracy or causality. Explain any proposed data correction with primary evidence; do not change a cell to make estimates agree.

Use the [runbook](docs/RUNBOOK.md) to run the relevant checks. UI changes need PT/EN, light/dark, keyboard and responsive review. English is generated from Portuguese sources and the translation dictionaries: edit those inputs rather than generated English files.

Do not overwrite a frozen package or its manifest. A new delivered version needs its own verification record. Never commit `.enso-runtime.json`, API keys, tokens or provider downloads outside the documented publication list.
